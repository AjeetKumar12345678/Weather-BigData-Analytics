# Weather Big Data Analytics

A real-time weather analysis project built using
Open-Meteo API, PySpark and Streamlit.

## Technologies

- Python
- Streamlit
- PySpark
- Pandas
- Open-Meteo API

## Features

- Search any location
- Real-time current weather
- Temperature analysis
- Humidity analysis
- Wind analysis
- Rainfall analysis
- PySpark data processing
- Interactive charts
- Hourly weather data

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
